# Changelog

## 0.1.0

- Typed immutable cell snapshots, formula/cache preservation, bounded A1 sheets
  and ordered named workbooks.
- Standalone tables, records, read-only rows/columns, explicit edits and atomic
  calculated columns; stable filtering, sorting and column views.
- Strict versioned native JSON and CSV/TSV interchange with explicit formula
  modes, input limits and atomic UTF-8 file destinations.
- Safe Markdown, HTML and ANSI/plain terminal tables with immutable presentation
  documents and approximate Unicode widths.
- Pure-Python 3.14+ distribution with zero runtime dependencies and MIT license.

Formula calculation, XLSX, Google Sheets, rich Markdown parsing, advanced
aggregation and persistent edit history are outside this release.
